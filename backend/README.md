# API Tézenas Immersions

Prototype 0.1.0 — diagnostic uniquement, sans données personnelles.

Déploiement Cloudflare Workers depuis la branche main, répertoire /backend, commande `npx wrangler deploy`.

GET /health : état du service. Les réservations sont désactivées jusqu'à la mise en place du stockage et des contrôles serveur.

Ne jamais enregistrer de secrets dans ce dépôt public.
